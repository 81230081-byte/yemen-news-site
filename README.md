# نبض اليمن — موقع أخبار تجريبي مجاني

واجهة عربية RTL لأخبار اليمن مع قسم خاص لتعز. يجلب العناوين والروابط من واجهة GDELT DOC API عبر Cloudflare Pages Function. GDELT هو فهرس/تجميع إخباري خارجي؛ قد تظهر عناوين بلغات مختلفة أو أخبار ذات صلة غير مباشرة، لذلك لا تعرض الصفحة الأخبار على أنها متحققة.

## النشر المجاني
1. أنشئ حسابًا في GitHub ثم مستودعًا جديدًا (Repository) باسم `yemen-news-site`.
2. ارفع الملفات والمجلد `functions/api/news.js` إلى جذر المستودع، مع الحفاظ على المجلدات.
3. أنشئ حسابًا في Cloudflare، ثم Workers & Pages → Create → Pages → Connect to Git.
4. اختر المستودع. اترك Framework preset على None، واجعل Build command `exit 0`، وBuild output directory `.`.
5. اضغط Deploy. سيعطيك Cloudflare رابطًا مجانيًا مثل `https://اسم-المشروع.pages.dev`.
6. اختبر الرابط ثم أضف `/api/news` في نهايته؛ يجب أن تظهر استجابة JSON بها articles.

## ملاحظات
- لا تحتاج لوحة تحكم أو قاعدة بيانات لهذا النموذج الأولي.
- التحديث يجري عند فتح الصفحة أو الضغط على «تحديث الأخبار»، مع تخزين مؤقت قصير من المصدر. ليس بثًا لحظيًا مضمونًا.
- يعتمد جلب الأخبار على خدمة GDELT الخارجية وتوفرها، وقد لا تكون كل النتائج عن اليمن مباشرة. راجع المصدر الأصلي دائمًا.
- الاسم والألوان قابلة للتغيير في `index.html`.
